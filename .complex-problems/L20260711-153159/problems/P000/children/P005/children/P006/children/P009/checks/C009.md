# 家庭授权撤销后的 Echo Context 主动回退复核

## Summary

R008 满足 P009：授权失败或撤销会把持久化 family context 主动切回本人，并沿既有 Context 通知链使 Echo、知识角色和治理队列一致回退。

## Evidence

- 纯策略模型覆盖 self、accepted family、revoked family 和 signed-out。
- 静态 gate 证明 freshness、持久化、通知、KBLite/coordinator persona 更新与 Echo runtime observer 全链存在。
- family repository/Echo authorization/release QA 和 Simulator build 均通过。

## Criteria Map

- authority 变化触发 reconcile：满足。
- 失效 Context 写回 self 并通知：满足。
- Echo 取消旧 runtime 并准备 self：满足。
- 正常 accepted family 不重置：纯策略和 guard 均证明。

## Execution Map

- R008 完成 freshness 约束、纯 policy、ContextStore/observer 链和 QA 接线。

## Stress Test

- revoked family 输入得到 fallback；同一输入改为 authorized 后保持 family，不产生误回退。

## Residual Risk

- 同账号刷新乱序与 coordinator invalidate 排序属于父问题的并发 follow-up，不否定 P009 主动回退逻辑本身。
