# Coordinator 授权失效线性化复核

## Summary

R011 满足 P013；独立复核确认角色/家庭失效会先轮换 epoch，再同步更新 queue generation，旧 callback 无法通过写入 guard，且未发现新阻断问题。

## Evidence

- epoch 模型证明 rotate 后旧 bound epoch 立即失效。
- static gate 固定 user/persona/family 三个失效入口与 `isCurrent` epoch 检查。
- 独立 agent 复核 callback 排队时序，确认 graph/base/outbox 写入前均被阻断。
- governance/async/release QA 与 Simulator build 通过。

## Criteria Map

- 立即轮换 epoch：满足。
- callback-before-invalidate：旧 epoch 在 queue block 前已失效，满足。
- API 返回前 queue 状态完成：queue-specific 同步执行，满足。
- 无自锁/main sync：queue identity 防重入，且不存在 main.sync，满足。

## Execution Map

- R011 完成 epoch state、coordinator 接入和发布 gate。

## Stress Test

- 模型执行 bind -> rotate -> old callback reject；独立源码时序复核覆盖已排队 callback。

## Residual Risk

- 真实高并发网络调度不做真机验证，但非真机目标已有模型、静态、编译和独立复核证据。
