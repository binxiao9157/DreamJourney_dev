# 用 owner/persona scope 守住知识同步并关闭未签名整库分享

## Problem Definition

KnowledgeSyncGraphEngine 只按 privacy scope 判断可同步，ownerless/wrong-owner/unaccepted-family 实体可能上传或从 authoritative remote 合并；KBLiteMultiUser 又允许文件自报身份或裸 graph 直接合并完整知识。

## Proposed Solution

为 sync engine 增加必填 `KnowledgeSyncAuthorizationScope`，所有 bootstrap/merge/delta/payload 同时校验 owner/persona/digitalHuman。Coordinator 只从 authorized current persona 构造 scope。ownerless legacy 视为本地 private，不上传。新增 FamilyKnowledgeSharePolicy：release 禁用完整图谱导出和任何无后端 grant 导入，裸 graph 永远拒绝；UI 展示明确未开放而非成功 0 条。

## Acceptance Criteria

- sync API 没有无 authorization 的生产调用。
- wrong owner、ownerless、persona/digital mismatch 不进入 payload/remote merge。
- accepted exact identity 保持同步，local legacy 保留不被 remote 删除。
- release 不生成 share package，不执行 package/raw graph import。
- QA-only legacy fixture 可显式运行但不能改变 production policy。
- model/static smoke 与 workspace build 通过。

## Verification Plan

扩展 three-way merge model smoke 覆盖 identity 矩阵；新增 share policy/static gate；运行 knowledge sync 现有模型、release checks 和 Simulator build。

## Risks

- 历史 ownerless 远端实体将不再进入可同步域，但本地副本保持，不做删除迁移。
- 当前没有后端 family share grant，因此 release 整库同步入口会关闭，这是预期边界。

## Assumptions

- 所有新知识实体已经由 Task 14/15 写入 owner/persona/digitalHuman。
- 后续整库共享必须另设后端签名 grant，不复用本地 JSON sourceUserId。
