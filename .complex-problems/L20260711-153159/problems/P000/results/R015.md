# Task 22 家庭关系授权与知识候选隔离结果

## Summary

Task 22 已完成当前非真机范围内的 P0 家庭关系授权与知识候选隔离。生产 authority 唯一来源是当前登录 owner 的后端手机号邀请 accepted 关系；KBPerson、本地 legacy member、QA fixture 和无签名整库分享均不能自动获得公开业务权限。Echo、知识提取、治理、同步、家庭音色和持久化 Context 共享同一授权边界。

## Done

- 建立默认拒绝、owner/source/status aware 的家庭关系授权模型。
- 将知识人物隔离为候选，不进入 accepted family repository。
- 绑定家庭仓库账号生命周期、请求 generation 和账号分区 override。
- 在 Echo 与持久化数字人 Context 前重新验证 accepted family，撤权后主动回退本人。
- 阻断 wrong-owner、ownerless legacy、未授权 family persona 的知识同步和生成；默认拒绝裸 graph 与无 grant 分享包。
- 使用不可变 persona authorization snapshot 和 coordinator authorization epoch 阻断旧 extraction/governance callback。
- 接入默认 release regression、release QA package、覆盖矩阵与状态文档。
