# 语义缓存隔离实现结果

## Summary

语义 embedding cache 已从进程级 raw entity ID 字典升级为 owner digest + user generation scope，并以 entity kind、entity ID fingerprint 和 searchable text fingerprint 作为 key。所有 cache 状态使用锁保护，账号切换/登出会同步激活新 scope 或清空；旧 warm task 在写入前重新校验 scope。

## Done

- 新增纯 `KBLiteSemanticCacheScope`、`KBLiteSemanticCacheKey` 和 stale-work policy。
- 移除全局 `isCacheWarm` 和 `embeddingCache[item.id]`。
- `KBLiteSemanticSearch` 的 activate/read/write/warm/search 全部采用 lock + scope guard。
- `KBLiteManager` 在 init/switch/save/search 路径捕获并传递同一 generation scope。
- 同 ID 的跨类型、跨账号和内容更新向量不再复用；key 不保存 raw userId 或正文。
