# 非真机 QA Gate 结果

## Summary

已将跨账号授权矩阵固化为 runtime 合同、脱敏 HTTP smoke、Swift 静态 guard 和 release regression 可选 gate，并完成后端与 iOS 非真机验证。

## Done

- `/config/runtime.auth.crossAccountPolicy` 暴露覆盖策略、诊断 headers、contractVersion=1 和 productionEnforceReady=false。
- HTTP smoke 覆盖邀请接收、家庭关怀、时间信件收件人，以及伪造 viewer 的 403 拒绝。
- 敏感关怀/时间信件/邀请路由直接绑定 bearer principal；不再依赖手机号 query 才能验证登录用户。
- smoke 不输出 token、手机号、用户 ID 或正文，且不调用全局 dispatch。
- QA 脚本接入 release package 和 `RUN_BACKEND_CROSS_ACCOUNT_AUTH_SHADOW_SMOKE=1`。
- 覆盖矩阵和 release feature matrix 已更新。
