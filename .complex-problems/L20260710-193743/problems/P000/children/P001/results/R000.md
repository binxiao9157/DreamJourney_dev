# 授权策略模型实现结果

## Summary

已用测试先行方式完成独立 `CrossAccountAuthorizationPolicy`，固定 owner、家庭关怀 viewer、时间信件收件人、家庭邀请接收人和 system-only 的授权语义。

## Done

- 新增固定枚举的 `AuthorizationPolicyDecision`，header 值不携带 PII。
- 已接受且 active 的家庭成员通过手机号稳定映射到登录 principal。
- 时间信件 viewer 必须与 principal 一致，并且必须是信件内有效家庭收件人。
- 家庭邀请手机号与 principal 绑定。
- 未分类路由明确返回 ownership fallback，不影响旧路由。

## Verification

- `python3 -m unittest tests.test_authorization_policy`：8 项通过。
- 测试先观察到缺少模块的预期失败，再实现至通过。

## Gaps

- 尚未接入 FastAPI middleware，因此当前策略不会改变或标记真实 HTTP 请求。
- Postgres/线上行为将在后续 HTTP smoke 与部署验收中验证。
