# Round 2A：产品定位、阶段范围与指标收敛

## Problem

当前资料把私人记忆助手、公开数字分身、家庭关怀、时间信件、声音复刻和认知平台同时描述为核心，导致 P0 失去优先级意义。需要以用户价值和现有工程证据为基础，明确目标用户、JTBD、主闭环、非目标、阶段范围、目标 IA 兼容策略和可验证指标。

## Success Criteria

- 给出唯一的一句话定位、核心目标用户和三个以内的核心 JTBD，并区分事实、推荐与待决策。
- 定义不依赖 Voice/Digital Human 的 Owner 私人记忆主闭环。
- 将全部需求重排为安全止损、Owner 核心、摄入与质量、受控发布、独立 Voice Beta、未来扩展阶段。
- 给出一个北极星候选指标和不超过三个阶段结果指标，指标具有事件口径和反作弊边界。
- 明确 Family/Care/TimeLetter、Publication/Visitor、Voice/Digital Human 的产品轨道和非目标。
- 现有三 Tab 与目标信息架构形成兼容映射，不直接要求本轮改 UI。
- 该问题属于 T006，因为产品范围是领域模型、决策登记和架构路线的输入前提。
