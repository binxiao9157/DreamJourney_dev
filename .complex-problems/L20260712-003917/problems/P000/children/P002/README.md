# Round 2：产品模型、范围与决策收敛

## Problem

新 PRD、Blueprint 和现有工程对 MVP 范围、Family/Care/TimeLetter、Publication/Visitor、Archive/Memory/Knowledge 等概念存在差异，需要形成唯一可执行产品定义。

## Success Criteria

- 产品定位、北极星、用户角色、核心闭环和 MVP 非目标一致。
- 领域词典明确 Source、Memory Candidate、Canonical Memory、Knowledge Projection、Persona、Conversation、Publication、Visitor 和 Runtime 边界。
- 私人域与公开人格域、Owner 与 Visitor、声音私人/公开授权完全隔离。
- 所有冲突项进入决策登记册，标注推荐、影响、默认安全策略和决策人。
- 产出 Product Spec V4 和产品决策登记册初稿。
