# iOS Identity-bound Proposal 合并与 Persona 本地策略已实现

## Summary

iOS KBLite 主链路已切为 proposal-first，并用同一 canonical persona identity 绑定会话提取、异步 completion、existing summary、Echo 本地 fallback 和实体合并。角色切换后的旧结果被丢弃，family 不再读取未标注 personal legacy 知识。

## Done

- 新增 `KBPersonaIdentity/Resolver/Policy`，统一 Echo 与 KBLite 身份。
- ConversationMemory 在会话结束时捕获 identity。
- KBLite 使用 envelope，校验 proposal schema/identity/tombstone 边界。
- 两阶段 proposal ID mapping 避免 local legacy 重复并重映射关系。
- legacy extraction/quick fallback 仍兼容，并写 persona/evidence/source metadata。
- summary/local generation 同时执行 privacy、persona、confidence 与 evidenceStatus 门禁。
- invalid proposal 不推进后端精提取水位。
