# 实现 principal 解析与 ownership shadow

## Objective

在不破坏 `BACKEND_API_TOKEN` legacy 调用的前提下解析 user access bearer，并对请求中的 actor userId 做 shadow ownership 对比。

## Acceptance Criteria

- legacy backend token 解析为 system principal，现有调用继续成功。
- 有效 user access 解析为 user principal；无效、过期、撤销 access 返回 `401`。
- payload、query、已知 path 和 `X-DreamJourney-User-Id` 的 actor claim 可形成 `match/mismatch/unclaimed`。
- shadow mismatch 不阻断请求，并通过安全 response header 可观察。
- 仅测试显式启用 enforce 时 mismatch 返回 `403`。
- 日志不包含 token、手机号或原始 userId。

## Verification Plan

- 后端 API 单测覆盖 system/user/mismatch/enforce。
- 真实 Uvicorn smoke 覆盖 shadow header 和正常业务请求体读取。
- 后端全量 verify 确认旧接口未回归。
