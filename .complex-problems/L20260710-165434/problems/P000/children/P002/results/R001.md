# Principal 与 ownership shadow 结果

## Summary

完成 system/user principal 双轨解析和 ownership shadow 诊断，中间件默认不改变现有业务授权结果。

## Done

- legacy `BACKEND_API_TOKEN` 解析为 system principal。
- opaque user bearer 解析为 user principal；无效、过期、轮换或撤销 token 返回 `401`。
- 从专用 actor header、顶层 JSON、query 和已知 user path 提取有限 ownership claim。
- 返回 `X-DreamJourney-Auth-Principal`、ownership mode/decision 安全 QA header。
- mismatch 日志只包含 userId hash 前缀和 path，不包含 token、手机号或原始 userId。
- shadow 模式允许 mismatch 继续；测试 enforce 模式明确返回 `403`。

## Verification

- `tests.test_auth_sessions` 覆盖 legacy、user、shadow 和 enforce。
- 本地 Uvicorn smoke 确认 JSON body 未被中间件消耗，match/mismatch 请求均正常完成。
- 155 项后端全量测试通过。

## Known Gaps

- 合法跨账号家庭/时间信件授权尚未建模，因此线上必须保持 `AUTH_OWNERSHIP_MODE=shadow`。
