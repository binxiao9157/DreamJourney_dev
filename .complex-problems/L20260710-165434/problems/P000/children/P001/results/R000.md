# 后端 opaque auth session 合同结果

## Summary

完成 opaque access/refresh session 的服务、内存与 Postgres 存储合同，并在现有 FastAPI 登录链路中接入签发、轮换、防重放和撤销。

## Done

- `/auth/login` 返回带明确过期时间的 `dja_` access token 与 `djr_` refresh token。
- 存储层只持久化 SHA-256 token hash 和安全会话元数据，不保存原始 token。
- `/auth/refresh` 原子消费 refresh token 并轮换两类 token；旧 refresh 重放和旧 access 均返回 `401`。
- `/auth/logout` 撤销当前 access 对应会话；账号最终清理同时删除 auth sessions。
- 保留原 `BACKEND_API_TOKEN` system principal 兼容路径。
- `/config/runtime` 暴露 auth session、TTL、refresh rotation 和 ownership mode 合同。

## Verification

- `python -m unittest tests.test_auth_sessions`：7 项通过。
- `python -m unittest tests.test_postgres_store`：29 项通过，包含 Postgres 会话保存与轮换 fake-store 合同。

- 本地真实 Uvicorn smoke：登录、用户 bearer、refresh 轮换、防重放、logout 撤销均通过，报告不输出 token。

## Known Gaps

- SMS 身份证明和生产 ownership enforce 不在本票范围。
