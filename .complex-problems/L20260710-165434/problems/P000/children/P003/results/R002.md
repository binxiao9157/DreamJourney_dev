# iOS Keychain auth session 与 gate 结果

## Summary

完成 iOS opaque auth session 的 Keychain 保存、用户 bearer 请求、并发 refresh 合并、单次重试和 logout 撤销清理，并纳入 release QA。

## Done

- 新增 `BackendAuthSessionContract/Store`，使用 KeychainAccess `afterFirstUnlockThisDeviceOnly` 保存 token。
- 登录使用 backend-only compatibility header，成功响应先校验并保存 auth session，再回调登录 UI。
- 自动请求同时发送 user access bearer、独立 backend compatibility header 和 session user actor hint。
- `401` 最多触发一次 refresh；并发失败请求共用 `authRefreshWaiters`，刷新后各自仅重试一次。
- refresh 失败按 sessionId 清理，避免旧请求删除后续新登录 session。
- logout 先构造撤销请求，再同步清理当前 session；本地 UserManager 退出已接入。
- 新增静态 guard、部署 smoke runner、release regression 开关和 QA package 清单。
