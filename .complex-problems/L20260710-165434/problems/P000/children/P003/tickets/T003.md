# 接入 iOS Keychain auth session 与非真机 gate

## Objective

让 iOS 安全保存后端 opaque session，在业务请求中发送用户 bearer，并在 access 失效时合并并发 refresh、只重试一次。

## Acceptance Criteria

- access/refresh token 只保存在 ThisDeviceOnly Keychain，不进入 UserDefaults 或日志。
- 登录成功先采纳 session，再进入已登录状态。
- 用户 bearer 与 legacy backend token 使用独立 header，ownership actor hint 与 session user 一致。
- 并发 `401` 共用一次 refresh；原请求最多重试一次，不形成递归刷新。
- logout 先发撤销请求并安全清理当前 session，旧回调不得删除后续新登录 session。
- 静态 guard、真实后端 smoke、release package 和 iPhoneOS generic build 通过。

## Verification Plan

- iOS 静态合同检查。
- 本地 Uvicorn auth session/ownership smoke。
- release QA package、项目 lint、generic iPhoneOS build。
