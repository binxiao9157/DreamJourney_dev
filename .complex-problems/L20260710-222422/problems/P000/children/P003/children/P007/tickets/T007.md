# 提交推送、部署 API 并运行线上 Ownership Gate

## Problem Definition

本地实现和 gate 已通过，但线上仍运行旧提交，尚未具备 54 路由 principal-bound 行为和新 runtime audit。

## Proposed Solution

- 审查两仓库 diff，仅提交 Task 11 相关源码、测试、QA 和 Lodestar 记录。
- 后端先提交推送 main，iOS 提交推送当前 feature 分支。
- SSH 到服务器，确认 tracked clean、备份 `.env`、fast-forward pull，仅重建/recreate API。
- 验证 health、容器、Postgres、ownership mode、route audit、timer。
- 运行 auth、cross-account、route ownership 三条 deployed smoke 并保存报告。

## Acceptance Criteria

- 两仓库远端包含清晰提交且工作区无遗漏。
- 服务器 API 提交与远端后端提交一致，Postgres/Redis 不重建。
- 三条 deployed smoke 全部通过，报告脱敏。
- timer active，global mode shadow，productionEnforceReady=false。

## Verification Plan

- push 后比较 local/remote SHA。
- 部署后请求 `/health` 与 `/config/runtime`。
- 运行三条 smoke，检查 JSON。
- 运行两仓库 `git diff --check` 与最终 status。

## Risks

- 部署期间 API 短暂重启；只重建 API 并保留数据容器。
- smoke 创建测试账号数据；使用随机手机号且不输出身份信息。

## Assumptions

- SSH alias、服务器 repo 和私密 access 文档未变化。
