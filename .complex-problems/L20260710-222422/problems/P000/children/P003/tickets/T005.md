# 固化 Ownership Audit Gate 并生成部署证据

## Problem Definition

当前实现与局部测试已通过，但缺少可重复的一键 audit gate、release regression 开关和部署环境 Postgres 证据，后续新增路由可能绕过分类。

## Proposed Solution

- 新增 iOS/后端静态 ownership audit check。
- 新增部署后端 HTTP smoke，验证 owner 正向、跨 owner 403、system-only 403、delegated smoke 兼容。
- 接入 `run-release-regression.sh` 可选开关，不影响默认公开 MVP 回归。
- 更新 Task 11 与 QA 文档。
- 运行全量后端测试、Swift QA、iOS generic build、`git diff --check`。
- 分别提交并推送两仓库，部署后端，运行线上 Postgres auth/cross-account/route audit smokes。

## Acceptance Criteria

- 新路由未分类会使 gate 失败。
- release regression 可通过环境开关运行 deployed ownership smoke。
- 两仓库构建与检查通过并有清晰提交。
- 线上健康、Postgres、global shadow、54/0 audit、owner/system 403、delegated 合法访问均有报告。

## Verification Plan

- 后端 `unittest discover`。
- 新静态 check 与 deployed HTTP smoke。
- release regression 相关开关检查。
- iPhoneOS generic Debug build。
- 部署后 health + 三个线上 smoke。

## Risks

- 线上用户数据不能进入测试报告；smoke 使用独立测试手机号并只输出 hash/计数。
- 部署必须只重建 API，不影响 Postgres/Redis 数据卷。

## Assumptions

- 服务器 SSH、私密 access 文档和部署环境仍可用。
- 用户已明确要求执行部署与线上验证。
