# iOS 每轮 Echo RAG 注入实现结果

## Summary

已把后端 generationContext 接到火山 Dialog 的当前 turn RAG 指令，并建立超时降级、单次提交和生命周期隔离。

## Done

- EchoContextPacket 解析 generationContext 版本、文本、来源、哈希和截断状态。
- DialogEngineManager 新增 `submitTurnKnowledgeContext`，真实路径发送 `SEDirectiveEventChatRagText`。
- Echo 最终 ASR 创建 turn gate，后端优先，0.9 秒后按当前 query 使用本地 KBLite。
- 旧服务器缺 generationContext、请求失败或未配置后端时均明确降级。
- lifecycle、user、turn 和单次提交校验阻止旧回调污染生成；旧 trace 仍进入历史但不覆盖最新 trace。
- 延迟回信只记录 trace，不提交生成 RAG。
- Echo 启动启用 turn-scoped 模式，生产 Dialog prompt 不再重复附加旧 KBLite/档案摘要；其他调用默认不变。
