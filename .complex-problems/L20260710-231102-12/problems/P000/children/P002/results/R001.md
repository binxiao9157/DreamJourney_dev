# iOS KBLite 生命周期与同步实现结果

## Summary

将 KBLite 从进程级隐式单例状态收敛为按用户显式生命周期，并接通 backend-first extraction、revision/change-feed 同步、离线规则降级和旧后端 snapshot fallback。

## Done

- KBLite 新增 `loadedUserId`、`switchUser(to:)` 和 generation guard；登出态内存为空且不持久化。
- legacy `kb_graph.json` 改为单次 move，避免复制给多个用户。
- UserManager 登录/登出、App 启动和 Scene 前台恢复接入知识生命周期。
- 新增 `KnowledgeSyncCoordinator`，串行合并 change feed、提交 mutation、处理 409、兼容旧 `/kb/sync`。
- 增加 graph fingerprint 和持久化 pending operationId，避免未变化前台同步空写，并保证丢响应重试幂等。
- KBLite 主提取改为后端 `/kb/extract`；后端未配置或失败时才执行本地规则。
- 新知识实体增加可选 privacyMetadata；新对话/图片分析实体标记 generationAllowed，旧实体默认保持 local-only。
- 新增 knowledge pipeline release guard，并把 coordinator 显式加入 Xcode target。

## Verification

- `swift scripts/QA/prd-stitch-ui/knowledge-pipeline-check.swift .` 通过。
- generic iOS Simulator Debug build 通过，bundle id 使用 `com.yxj.dreamjourney.app`。
- `git diff --check` 在阶段检查中通过。
- 静态 guard 证明 KBLite 不再调用 `DeepSeekService.shared.extractKnowledge`，且登录/登出/前台触发点和新客户端合同存在。

## Known Gaps

- 当前机器的真实 simulator destination 不支持此工程的 x86_64 Tencent SDK 组合，因此本阶段完成 generic simulator build，未运行可安装 UIQA。
- P0 graph mutation 仍为整图 replacement；复杂实体冲突审核留给 P1。
- 旧知识实体没有隐私元数据时继续 local-only，不自动扩大同步范围。
