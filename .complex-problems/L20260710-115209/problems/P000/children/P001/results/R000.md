# 音色槽持久化与独占分配已实现

## Summary

内存和 Postgres store 已具备配置槽注册、逻辑 profile 独占分配、查询、状态更新和退休能力。Postgres 使用单条 CTE 与 `FOR UPDATE SKIP LOCKED` 完成抢占。

## Done

- 新增 `voice_clone_slots` 结构化表及用户索引。
- 新增 `allocate_voice_clone_slot`、`get_voice_clone_slot`、`list_voice_clone_slots`、`update_voice_clone_slot`。
- 同一逻辑 profile 重复申请返回原槽；不同 profile 独占；满容量返回 `None`。
- retired 槽保留绑定且不再回池。
- Fake Postgres 和内存 store 测试覆盖分配、复用、容量、训练次数和退休。
