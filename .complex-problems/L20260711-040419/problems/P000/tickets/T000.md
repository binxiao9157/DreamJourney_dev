# 实现知识治理权威动作与来源删除级联

## Problem Definition

当前 Mutation V2 能同步任意实体 upsert/tombstone，但没有可证明用户确认、拒绝、纠正和来源删除语义的权威合同。客户端若直接改写实体，会丢失原始知识与证据历史；来源被删除后，引用它的知识仍可能进入 Echo。iOS 也缺少串行提交治理动作并消费权威 snapshot 的能力。

## Proposed Solution

在后端新增 owner-only `POST /kb/governance/actions`，由当前 snapshot 和 allowlisted action 构建 Mutation V2。实现 `confirm`、`reject`、`correct`、`deleteSource` 四种动作：确认/拒绝保留实体和来源，纠正把原实体标记 `superseded` 并创建稳定 replacement，删除来源把所有直接引用实体标记 `superseded` 并移除该 ref。所有动作记录不含正文的治理 metadata，并沿用 operation ID、base revision、Postgres 原子 mutation 和 change feed。

iOS 增加治理 action/response/metadata 模型、backend client，并由 `KnowledgeSyncCoordinator` 串行调用、校验 user/persona generation、应用权威 graph 和更新 remote base。公开 UI 不在本票范围，新增非真机模型/静态/后端 smoke 与 release 可选 gate。

## Acceptance Criteria

- 四类 action 均经过严格 schema、timestamp、entity type、owner/persona 和 correction allowlist 校验。
- correction 原实体保持可审计并变为 `superseded`，replacement 为新 ID、`confirmed`，关系与来源合法。
- deleteSource 覆盖四类实体的全部直接 source ref，受影响实体不再可进入 Context/Echo。
- endpoint 复用 Mutation V2 revision、operation ID 幂等、权威 graph 和 change feed；跨账号 principal 被拒绝。
- iOS 能构造四类请求、解析治理摘要、应用权威结果，并拒绝旧用户/旧 persona 回调。
- proposal、Mutation V2、三方合并和 evidence/Context 既有回归不退化。
- 后端全量测试、跨仓库 gate、Simulator 和 generic iPhoneOS build、`git diff --check` 通过。

## Verification Plan

1. 后端纯函数与 FastAPI 测试覆盖四类动作、非法状态、非法 correction、source not found、revision conflict、重复 operation 和跨账号。
2. 后端 smoke 验证治理 mutation 写入 snapshot/change feed，Context 不选择 rejected/superseded，corrected replacement 可被选择。
3. iOS Swift 模型 smoke 验证编码/解析、identity gate、权威 snapshot application 和 fallback 边界。
4. 将组合 gate 接入 `run-release-regression.sh` 可选开关，同时保持日常静态 guard。
5. 运行后端 verify、release regression、generic Simulator/iPhoneOS build 和 diff check。

## Risks

- correction 关系若指向不存在实体可能产生悬空引用，必须基于 snapshot 做关系校验/净化。
- 来源删除可能影响多个 persona，需明确按 owner 全域撤销直接证据并保持审计，不误删实体。
- iOS 治理请求与普通同步并发可能覆盖结果，必须复用同一串行协调器和 generation gate。
- 公开 UI 尚未定稿，本票不能通过临时入口扩大产品范围。

## Assumptions

- 当前 Mutation V2、route ownership middleware 和 Context evidence filter 是权威基础。
- `rejected/superseded` 继续不允许进入生成。
- source deletion 是证据撤销而不是物理实体删除。
- 本轮不推送、不部署、不做真机验证。
