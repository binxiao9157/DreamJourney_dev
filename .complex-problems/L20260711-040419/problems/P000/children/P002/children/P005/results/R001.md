# Archive ID 跨 Owner 冲突保护执行结果

## Summary

Archive ID 现在在 memory/Postgres/API 三层都保持不可跨 owner 复用，同 owner 更新继续兼容。

## Done

- 新增 `ArchiveItemOwnershipConflict`。
- InMemoryStore 增加 archive lock，并在写入时拒绝其他 owner 的同 ID。
- Postgres archive 专用 owner-aware upsert 不再使用会重写 `user_id` 的 generic helper。
- `/archive/photos` 和 `/archive/items` 将冲突映射为无 owner 泄露的 409 code。
- 增加 memory、Postgres fake-store 和 API 回归。

## Verification

- 17 项定向 archive/governance tests 通过。
- `compileall` 和 `git diff --check` 通过。

## Known Gaps

- 不自动修复历史上已被错误覆盖 owner 的记录。
- Archive 删除组合事务属于 P006。
