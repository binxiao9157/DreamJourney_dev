# DeleteSource Endpoint 与 Context 执行结果

## Summary

Archive DELETE 已接入 canonical `memoryArchiveItem` 来源撤销，并通过组合事务保证知识先失效和素材删除一起提交；Context 不再使用被撤销知识。

## Done

- DELETE 支持可选 operationId，旧调用缺失时自动生成。
- 服务端从当前 snapshot 构建 deleteSource Mutation V2；无 source 命中时以 mutation=None 删除且 revision 不变。
- 调用组合 store 原语并映射 missing、sealed、revision、validation。
- 响应保留 status/id/item，新增无正文 cascade action/operation/revision/duplicate/count/sourceMatched。
- duplicate operation 从 stored mutation 恢复 summary；非治理 operation 冲突返回 409，避免伪成功。
- API 测试证明四类实体 superseded、source ref 移除、change feed 单增量、重复幂等和 Context 不含旧事实。

## Verification

- Postgres/store/governance/context 组合 68 项测试通过。
- ArchiveAPITests 24 项通过。
- compileall 与 diff check 通过。

## Known Gaps

- legacy `archiveImageAnalysis/session-N` ref 无法按 item ID 自动匹配，需后续迁移或重新提取。
- iOS 删除操作提供稳定 operationId 与消费 cascade 属于 P003。
