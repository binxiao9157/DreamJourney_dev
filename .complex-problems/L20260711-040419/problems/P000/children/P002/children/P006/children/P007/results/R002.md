# Store 组合删除事务原语执行结果

## Summary

MemoryStore 与 PostgresStore 已提供统一的 Archive + Knowledge 组合删除原语，Postgres 在单 transaction 中提交 mutation/change feed 与 archive delete。

## Done

- 新增 archive missing/forbidden 异常和 sealed timeLetter 判定。
- MemoryStore 在 archive/knowledge 可重入锁下完成 duplicate、revision、mutation 和删除。
- Postgres 使用 knowledge advisory lock、archive row lock、snapshot row lock和单次 commit；异常 rollback。
- 支持 mutation=None 的无知识引用删除，不伪增 revision/change。
- mutation operation 重试返回 stored revision/mutation，不重复写 change。
- 增加 memory 与 Postgres 成功、无 mutation、conflict、sealed、missing、duplicate、SQL rollback 测试。
