# 实现后端 canonical conversation-turn 来源与只读 source audit

## Problem Definition

后端 V2 proposal 继承请求级模糊来源，source title 口径不完整，且没有不泄露正文/ID 的历史来源审计 API。

## Proposed Solution

从已验证的 sessionId 和每个实体 sourceTurnIndices 派生 `conversationTurn + session-{sessionId}:turn-{index}`；统一 source-kind title；实现纯 audit classifier 和 owner-bound preview endpoint，只返回 revision/计数/策略。

## Acceptance Criteria

- 每个实体只携带自身有效 turn refs，并保持 existing non-conversation refs 的兼容合并边界。
- legacy `conversationSession/archiveImageAnalysis`、canonical、unknown 可区分。
- audit response 不含 graph、entity text、source ID 或 title。
- endpoint 受 knowledge owner principal 约束并登记 route ownership。
- 不提供 apply migration，不修改 snapshot。
- 后端单测、FastAPI smoke 与 diff check 通过。

## Verification Plan

新增 proposal/privacy/audit/API/ownership 测试，运行针对性测试与 `scripts/verify_backend.sh`。
