# 固化来源身份验证入口和产品知识库口径

## Problem Definition

来源身份代码已存在，但没有统一 gate、release 防回退检查和准确的交付文档，后续修改可能重新产生 ambiguous refs 或误导历史迁移。

## Proposed Solution

新增 `run-knowledge-source-identity-gate.sh` 组合 iOS Swift smoke/static check 与后端定向测试；默认接入 release regression，并由 release QA package check 检查脚本和关键合同。修正知识库架构文档，新增 Task 19 状态说明与验证命令。

## Acceptance Criteria

- 跨仓 gate 一键通过并能在缺少后端仓库时明确失败。
- release regression 默认运行 gate，报告记录结果。
- release package guard 检查 gate、canonical kinds、legacy 禁止生成和只读 audit endpoint。
- 文档准确说明来源种类、历史边界、无自动迁移策略及验证方式。
- 后端 verify、iOS generic Simulator/iPhoneOS build、release regression、diff check 通过。

## Verification Plan

运行跨仓 gate、release QA package check、后端 verify、两类 iOS generic build 和不含真机步骤的 release regression；检查报告与 git diff。

## Risks

- release regression 已较大，新增步骤必须保持纯本地且确定性。
- 文档修正不能改写历史状态证据，只补充当前 authoritative 结论。

## Assumptions

- 后端仓库默认位于 iOS 同级 `DreamJourneyBackend`，同时允许 `BACKEND_ROOT` 覆盖。
- 不运行真机和 provider 相关可选 gates。
