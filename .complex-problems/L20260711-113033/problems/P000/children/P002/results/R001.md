# iOS canonical 来源生成与 typed audit consumer 执行结果

## Summary

iOS 新知识来源已统一到 canonical 合同，并接入聚合只读审计 consumer；历史 legacy refs 保持只读，不自动迁移。

## Done

- 新对话文本来源统一生成为 `conversationTurn + session-{sessionId}:turn-{turnIndex}`。
- 新对话照片来源统一生成为 `conversationPhoto + photo-{stableAssetId}`，拒绝绝对路径和非法资源 ID。
- 新知识合并时保留既有来源并追加 canonical 来源，不自动改写历史 legacy refs。
- iOS 后端请求声明 `sourceContractVersion=1`，不再提交可伪造的 request-level source refs。
- 新增 `/kb/source-ref-audit/{userId}` 的严格 typed consumer，仅解析聚合计数和建议动作。
- 新增本地 aggregate audit 与模型、client 静态检查脚本。
