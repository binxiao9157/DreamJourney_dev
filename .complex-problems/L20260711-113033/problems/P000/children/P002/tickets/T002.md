# 实现 iOS canonical source identity 与 typed audit consumer

## Problem Definition

iOS 新知识仍产生 `conversationSession` 和 `archiveImageAnalysis`，对话照片文件名只有秒级稳定性；客户端也无法类型安全读取后端 source-ref audit。

## Proposed Solution

新增纯 source identity policy；本地提取按 session/turn 生成 `conversationTurn`，对话照片使用 UUID asset ID 生成 `conversationPhoto`，extraction request 只声明 contract/scope；增加 typed audit response/client 与 QA-only local audit snapshot。

## Acceptance Criteria

- 新本地文字来源精确到 turn；现有 refs 合并不丢失。
- 新对话照片来源稳定、唯一且不含绝对路径。
- 请求 payload 不再发送 `conversationSession/archiveImageAnalysis`。
- audit typed parser 严格验证 schema/counts/action，不暴露 graph/ID。
- 不自动改写旧 graph，不改变公开 UI。
- model/static smoke、diff check 和 Simulator build 通过。

## Verification Plan

先补 pure model smoke 与 source static guard，再修改业务代码，运行知识 gate、QA package 和 iOS build。
