# 实现 canonical 来源身份与历史来源只读审计

## 目标

在不自动迁移现有知识图谱、不改变公开 UI 的前提下，统一新知识的来源身份：后端 V2 proposal 派生精确 conversation-turn refs，iOS 本地提取与对话照片使用 canonical refs，并提供不含正文/ID 的历史来源 audit preview。

## 验收标准

- 后端 proposal、privacy、source title 和 audit 使用同一 source-kind 合同。
- iOS 不再产生 `conversationSession` 或 `archiveImageAnalysis` 新来源。
- 旧来源保持可读且只被审计，不被误映射为 Archive item。
- Archive 删除仍只级联 `memoryArchiveItem`。
- 后端、iOS、跨仓 gate、构建、release regression 和线上只读 audit smoke 通过。
- 分仓提交推送，后端按需部署，不做真机。

## 验证方案

- 后端单测覆盖 turn 派生、audit redaction、legacy/unknown 分类和 owner isolation。
- iOS pure model/static smoke 覆盖 canonical refs、photo ID 去路径和 legacy audit。
- 运行全量后端、知识 gate、Simulator/generic iPhoneOS build 和 release regression。
