# P0 数字人 Session Lease 与并发控制根问题成功检查

## 结论

结合 `R001` 与 `R002`，根问题已在约定的非真机范围内解决，判定成功。

## 原始目标映射

- 安全持久化：实现内存/Postgres lease store，且不保存腾讯 credential。
- 会话复用与角色切换：同设备同上下文复用；同设备新上下文使旧 lease 失效。
- 并发控制：不同设备竞争同一 provider 资源时使用 Postgres advisory lock 和容量限制。
- 故障恢复：heartbeat 续租、显式 release、TTL 过期和幂等 release 均已完成。
- iOS 生命周期：活跃 runtime 心跳；角色/页面/后台宽限/provider 失败释放；用户 stop 保留。
- 异步隔离：stale session success 不再被静默丢弃，而是主动 release。
- 自动化：后端专项/全量、iOS 静态检查、模拟器 smoke、构建、release gate 均通过。

## 未扩大结论

本检查不把代码完成等同于线上部署完成，也不把模拟器合同证明等同于真实腾讯配额、画面、声音、口型、打断和麦克风恢复验收。以上仍是后续部署及真机阶段的明确风险项。
