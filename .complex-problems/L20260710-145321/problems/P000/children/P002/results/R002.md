# Session Lease API、iOS 消费与组合验收结果

## 完成内容

- 后端新增内存与 Postgres `digital_human_sessions` 持久化，保存安全 lease 元数据，不保存腾讯 `appkey`、`accesstoken` 或会话 credential。
- `/digital-human/sessions` 升级为合同 v2，支持同设备同上下文复用、同设备角色切换替换、跨设备容量冲突、TTL 回收和结构化 `409`。
- 新增 heartbeat 与幂等 release 接口，并在 `/config/runtime.digitalHuman.sessionLease` 暴露 TTL、心跳间隔、并发容量和端点模板。
- Postgres 容量仲裁使用 advisory transaction lock，防止多 worker 同时占用同一设备或 provider 资源。
- iOS 新增 lease/runtime capability 模型和 heartbeat/release client；当前 session 活跃时定时续租，页面退出、角色切换、后台宽限期到期、provider 失败时统一释放。
- iOS 对成功但已过期的异步 session 回调执行显式 release；用户只停止当前对话时保留 lease 和腾讯 runtime。
- 模拟器 runtime stub smoke 已升级为 create -> heartbeat -> release 闭环，避免 QA 自身长期占用并发。
- 新增可选 release gate `RUN_DIGITAL_HUMAN_SESSION_LEASE_GATE=1`，并接入 release QA 包静态检查。
