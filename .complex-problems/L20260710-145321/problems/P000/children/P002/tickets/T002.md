# 交付 Session Lease v2 API 与 iOS 生命周期消费

## Problem Definition

Lease store 已实现，但现有 API 仍无状态，iOS 也不知道 heartbeat/release，尚不能形成用户可感知的并发保护。

## Proposed Solution

升级后端 session contract v2，新增 runtime lease capability、结构化 409、heartbeat/release；补 API 和 smoke。iOS 增加 lease model/client，绑定当前 session generation 定时 heartbeat，在统一 runtime release helper 和 stale response 路径释放；用户 stop 保留。新增静态 guard、组合 smoke 与 release regression 开关。

## Acceptance Criteria

- API 测试覆盖 create/reuse/conflict/heartbeat/release/expiry 和 runtime config。
- iOS client/contract 与 Echo 生命周期语义由静态 guard 和模拟器 smoke 证明。
- 后端凭据不进入 lease store/响应诊断。
- 后端验证、iOS 构建、release regression 和 diff check 通过。

## Verification Plan

测试先行；运行 backend verify、session lease smoke、iOS guard、runtime stub/lifecycle smoke、Debug build、release QA 和 whitespace check。

## Risks

- 网络 heartbeat 失败需要有限重试，不能因一次瞬时错误销毁数字人。
- 旧 session 响应必须 release，但不能释放当前新 session。

## Assumptions

- Store R000 是稳定基础。
- 本轮不依赖真实腾讯 SDK 或真机。
