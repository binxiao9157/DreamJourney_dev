# 后端 Session Lease Store 实施结果

## Summary

已为 InMemoryStore 和 PostgresStore 增加一致的数字人 session lease acquire、heartbeat、release、get 语义，并通过数据库事务 advisory lock 完成多 worker 容量仲裁。

## Done

- 新增 `digital_human_sessions` 表及 resource/status、user/device 索引。
- acquire 支持同 context 复用、同设备旧 context 释放、跨设备容量冲突和过期 lease 回收。
- heartbeat 校验 user/device owner，仅延长未过期 active lease。
- release 支持幂等 `released/alreadyReleased/alreadyExpired`。
- 账号最终清理同步移除数字人 lease。
- 持久化 payload 仅含 lease 元数据，不含 appkey/accesstoken。

## Verification

- `tests.test_postgres_store` 28 项通过。
- InMemoryStore 覆盖复用、替换、冲突、heartbeat、幂等 release、TTL。
- PostgresStore 覆盖 advisory lock、复用、冲突、heartbeat、release、TTL 和 schema。
- `git diff --check` 通过。

## Known Gaps

- API 路由和 iOS 消费尚属于后续子任务。
- 真实 Postgres 容器 smoke 在完整后端 gate 阶段执行。
