## Criteria Map

- 单 runtime/session 与 audio owner：显式 runtime generation + 单值 owner + 重复 runtime close。

- 旧 PCM 不再发送：每个 chunk/final 校验 token、requestID、context。
- 配额立即 fallback：quota helper 排除 recovery，统一 release 回普通 Echo。
- QA/build：静态 release、组合 gate、模拟器构建、diff check 均通过。
