# P003 runtime、audio owner 与 fallback 收敛结果

## Summary

Echo runtime 已显式绑定 lifecycle generation，旧 session/角色无法拥有音频；停止、打断、PCM 尾段、麦克风恢复和配额 fallback 均受当前代际约束。

## Done

- runtime 记录并校验 `digitalHumanRuntimeLifecycleGeneration`，重复 runtime 在绑定前关闭。
- runtime 状态回调、复刻合成、PCM chunk/final、TextOver 与恢复麦克风均校验当前 token。
- 用户停止/点击打断仅终止当前交互并保留 session；页面退出与 provider 终止失败走统一 release。
- 配额失败排除自动 recovery，立即回普通 Echo，清空旧请求与旧音频 owner。
- PCM mock stub 按生产路径登记 generation，组合回归发送 402 个连续 chunk 和 final 成功。
- Phase 2 guard 与 lifecycle coordinator check 接入 release regression。

## Verification

- 完整静态 release regression 通过。
- 腾讯数字人非真机组合 gate 通过。
- PCM mock：`completed=true`、`sequenceIsContiguous=true`、`finalChunkObserved=true`、`interruptProbeCompleted=true`。
- iOS Debug simulator build 与 `git diff --check` 通过。
