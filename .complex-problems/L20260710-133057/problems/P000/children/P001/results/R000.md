# P001 统一生命周期异步隔离结果

## Summary

统一 Echo 数字人 session 与交互异步回调的 generation 边界，旧角色、旧轮次和页面退出后的回调不再改变当前状态。

## Done

- 新增统一的 `DigitalHumanLifecycleToken`，分别跟踪 session generation 与 interaction generation。
- 角色切换、页面退出会使旧 session/交互异步回调失效；用户停止、点击打断只使旧交互回调失效，不销毁腾讯 session。
- 会话能力、会话创建、复刻合成、Context Packet、PCM 分块与尾包、TextOver 超时、语音配置和麦克风恢复均接入 generation guard。
- 麦克风权限与 provider handoff 延迟回调接入当前交互 token。
- DialogEngine 的 ASR/TTS/流式回复回调只消费当前有效交互。
