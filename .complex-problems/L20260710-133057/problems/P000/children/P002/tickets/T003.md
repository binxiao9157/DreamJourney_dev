# 后台 session 宽限释放与 UIQA 回归

## Problem Definition

Echo 进入后台会立即关闭腾讯 runtime，短暂切换应用导致反复建连；但无限保留又会长期占用并发配额。

## Proposed Solution

将立即释放改为带 generation/context 的 8 秒可取消 lease。前台恢复取消 lease 并保留 session，lease 到期才失效 lifecycle 并关闭 runtime。扩展 UIQA，分别验证前台取消和模拟到期释放。

## Acceptance Criteria

- 后台暂停不会立即移除 provider view。
- 宽限期内前台恢复取消 lease，不自动启动麦克风。
- 到期只在 lease/context/session token 仍有效时释放。
- 页面退出取消 lease 并立即释放。
- lifecycle UIQA 可验证取消与到期两条路径。

## Verification Plan

运行生命周期纯状态检查、Phase 2 静态检查、模拟器 lifecycle UIQA smoke，并执行 iOS Simulator Debug 构建。

## Risks

- iOS 可能在后台挂起主队列，实际释放时间可能晚于 8 秒，但不会早于宽限或跨 generation 误释放。

## Assumptions

- 短暂切后台优先保留现有 session；超过宽限允许前台重新创建。
