# P002 后台 session 宽限 lease 复核

## Summary

代码、纯状态检查与模拟器 UIQA 同时覆盖 lease 取消和到期释放，原始后台立即释放问题已解决。

## Evidence

- UIQA 结果：`backgroundLeaseScheduled=true`、`backgroundLeaseCancelled=true`、`backgroundLeaseExpired=true`。
- UIQA 结果：`providerViewPreserved=true`、`runtimeReleasedAfterGrace=true`、`microphoneAutoStart=false`。
- Phase 2 静态检查确认后台入口不再直接调用 runtime release。

## Criteria Map

- 后台只暂停并安排 lease：源码检查与 runtime log。
- 前台取消并保留 provider：UIQA cancel 分支。
- 当前 lease 到期才释放：generation 状态检查与 UIQA expiry 分支。
- 页面退出取消并释放：源码 guard。
- 可重复模拟器验证：一键 lifecycle smoke 已通过。

## Execution Map

- R002：生产实现、release wiring、模拟器 smoke 与截图证据。

## Stress Test

- 同一次 smoke 先取消一个 lease，再创建第二个 lease 并等待到期，验证被取消任务不会误释放、当前任务可释放。

## Residual Risk

- 真机后台调度可能因系统挂起晚于 8 秒，属于允许的延迟释放，不会导致跨 generation 误释放。
