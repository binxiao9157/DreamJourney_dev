# 收敛 Echo 数字人异步代际与生命周期边界

## Problem Definition

Echo 已有多个局部 request/context guard，但角色切换、后台、页面退出、TTS 合成、PCM 定时发送和麦克风延迟恢复没有统一代际。短暂后台会立即关闭 session，配额错误仍会自动重试，容易产生旧角色回调、重复 session、错误 audio owner 或旧音频尾包。

## Proposed Solution

在现有 `DigitalHumanConversationCoordinator` 附近增加轻量生命周期协调器，集中维护 generation token、当前 context、session 绑定和后台释放 lease。Echo 每次角色切换、页面退出、终止失败或后台 lease 到期时推进代际；所有异步回调捕获 token 并在执行前校验。保留现有 request ID/context key 作为请求级细化保护。

后台改为可取消宽限释放；用户停止只打断当前播放并保留 runtime；页面退出立即失效代际并关闭 runtime。配额错误不再进入自动恢复。点击打断、provider 完成、PCM chunk/final 和麦克风恢复全部增加代际检查。通过纯状态检查、静态 guard 和扩展模拟器 lifecycle smoke 验证。

## Acceptance Criteria

- 角色切换后旧 session/capability/synthesis/PCM/resume 回调均无法生效。
- 任何时刻只存在一个当前 runtime 与一个显式 audio owner。
- 用户停止保留 session，页面退出释放 session。
- 后台宽限期内回前台取消释放，过期才关闭 runtime。
- 配额满直接普通 Echo fallback，不自动重连。
- 当前代际的点击打断和 provider 完成可以恢复麦克风，旧代际不能。
- Phase 2 静态检查、模拟器 lifecycle smoke、组合 gate、构建和 diff check 通过。

## Verification Plan

先增加针对 coordinator 与 Echo 源码合同的失败检查；再扩展 lifecycle UIQA，覆盖 generation 前进、旧 token 拒绝、后台 lease 取消/过期、session 保留与 quota 不重试。最后运行现有 audio-owner/stop guard、数字人组合 gate、release QA package 和通用模拟器构建。

## Risks

- 过度失效 generation 可能让当前有效回调被丢弃，需要只在角色/页面/后台过期/终止失败边界推进。
- 后台宽限期过长会占用腾讯并发，过短则失去收益；首版采用固定短时常量并可通过 UIQA 覆盖。
- 不做真机测试，实际 AVAudioSession 和腾讯 SDK 时序仍保留外部验收风险。

## Assumptions

- 后端 session 与声音复刻合同保持不变。
- 现有停止不销毁 session 和 request/context guard 继续保留。
- 本阶段仅实现点击打断，不实现全双工 VAD。
