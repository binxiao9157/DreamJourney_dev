## Criteria Map

- 旧角色/旧页面回调隔离：统一 session/interaction generation，session、capability、语音配置、合成、Context Packet、PCM 与延迟恢复均校验 token；对应 R000、R003。
- 单 runtime 与单 audio owner：runtime 绑定 generation，新 runtime 绑定前关闭旧 runtime，路由仅接受当前 generation；对应 R003。
- 停止保留、退出释放：interaction invalidation 不改变 session generation，`viewWillDisappear` 无条件调用统一 release helper；对应 R000、R003。
- 后台宽限：8 秒 lease、前台取消、过期释放和不自动开麦均有 UIQA 证据；对应 R002。
- 配额立即 fallback：配额错误从 recovery policy 排除并统一回落普通 Echo；对应 R003。
- 点击打断及恢复：打断使旧 interaction token 失效，恢复只接受当前 token，PCM 失败保留恢复标记；对应 R003。
- 非真机 QA：Phase 2 guard、纯状态测试、lifecycle smoke、runtime stub、PCM mock、release regression、构建和 diff check 均通过；对应 R001-R004。

## Stress Test

- 角色或 context 在请求返回前发生变化：旧 token 无法安装 runtime、播放 PCM 或恢复麦克风。
- App 短暂切后台后立即回来：lease 被取消，provider view 保留且麦克风不自动启动。
- App 超过宽限期留在后台：当前 lease 到期后 runtime 被释放，旧 lease/回调不能再次生效。
- 腾讯配额错误：不进入一次性重试，释放 provider 并切换普通 Echo，避免上一角色声音残留。
- PCM chunk/final 失败：清理失败 request 但保留当前轮恢复意图，避免永久停在 speaking/loading。
