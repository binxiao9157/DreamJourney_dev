# Echo 数字人稳定性阶段 2 实施结果

## Summary

已在不改变公开 UI、不调整后端合同且不执行真机验收的边界内，完成 Echo 数字人 lifecycle generation、后台 session 宽限释放、单 runtime/音频 owner、点击打断、PCM 尾段隔离、麦克风恢复和配额 fallback 的收敛。

## Done

- 引入统一 lifecycle token，区分 session generation 与 interaction generation；角色切换、页面退出和过期后台 lease 会使旧 session 回调失效，停止/打断只使旧交互回调失效。
- session、runtime state、语音能力、实时语音配置、复刻合成、Context Packet、PCM chunk/final、TextOver timeout 和延迟恢复均校验当前 token。
- runtime 显式绑定 lifecycle generation；新 runtime 绑定前关闭旧 runtime，只有当前 generation 可以占用腾讯 audio owner 或驱动口型。
- 停止对话保留腾讯 session；页面退出无条件释放 runtime；后台进入 8 秒可取消宽限期，前台及时返回不重建 session，宽限到期才释放。
- 点击说话期间可中断 provider 播放并恢复聆听；PCM 失败保留恢复标记，旧 PCM 尾段和旧异步恢复不会进入新轮次。
- 腾讯配额错误立即回落普通 Echo，不参与自动重连，也不会继续保留上一角色音频。
- runtime stub smoke 统一使用本机 QA Bundle ID `com.yxj.dreamjourney.app` 和 Team `2BTR77V3R8`，并保留私密 xcconfig 清空能力。
- 子结果：R000、R001、R002、R003。
