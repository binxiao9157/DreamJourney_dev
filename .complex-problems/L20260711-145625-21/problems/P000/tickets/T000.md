# 建立账号绑定且默认拒绝的 Widget 知识快照链路

## Problem Definition

当前 `KBLiteManager` 将全部知识事件的标题、描述和日期无条件写入共享 App Group 文件，Widget 无法验证快照所属账号，也不会在登出或切换账号后主动刷新已缓存 timeline。主 App 与 Widget target 同时缺少完整的扩展嵌入、Bundle ID 继承和 App Group entitlement 合同，导致功能不可交付且存在跨账号旧内容展示、未授权知识外泄和旧异步保存覆盖新身份数据的风险。

## Proposed Solution

建立版本化 Widget 快照 v2 和独立的隐私策略/存储层。隐私策略默认拒绝，只允许当前 owner、`generationAllowed`、显式 `summaryAllowed`、`personal`、`confirmed` 的事件生成不含正文和原始标识符的最小摘要。存储层使用 owner digest 与 KBLite generation 绑定发布，账号切换或登出时先撤销 active owner、删除快照并刷新 Widget，旧 generation 的延迟发布必须被拒绝。Widget 读取端校验 schema 与 active owner digest，任何缺失、不匹配、损坏或旧格式都返回空态。补齐扩展嵌入、Bundle ID 继承、双方 entitlement 和可配置 App Group build setting，并通过纯模型 smoke、静态 gate、模拟器与通用 iPhoneOS 构建验证。

## Acceptance Criteria

- legacy/default、非当前 owner、非 personal、非 confirmed、非 generationAllowed 或未显式 summaryAllowed 的事件均不进入快照。
- 快照只包含 schema、owner digest、生成时间和最小事件摘要，不含 raw owner/event/source ID、description、sourceRefs 或其他知识正文。
- Widget 对 active owner 缺失或不匹配、旧 schema、损坏 JSON 一律返回空态。
- 账号切换与登出先使旧快照失效并 reload timeline；旧 generation publish 无法覆盖新用户或登出状态。
- 主 App 包含 Widget extension，Widget Bundle ID 跟随主 App，两个 target 使用相同可配置 App Group entitlement。
- 新模型 smoke、静态检查、release QA package、release regression、Simulator build、generic iPhoneOS build 和 `git diff --check` 全部通过。
- 文档明确 App Group Developer Portal/provisioning 和真实 Widget Gallery 仍需外部真机验收，本任务不作真机完成声明。

## Verification Plan

先增加纯 Swift 模型 smoke，覆盖隐私组合矩阵、字段脱敏、owner digest、generation 拒绝和 provider fail-closed；再增加静态 gate 检查 entitlement、bundle 继承、扩展嵌入、timeline reload 与旧无条件导出已移除。实现完成后运行相关 smoke、release QA package、完整 release regression、模拟器构建、generic iPhoneOS 构建和 `git diff --check`，并检查构建产物包含 `.appex` 及其配置。

## Risks

- Apple Developer Portal 尚未注册目标 App Group 时，真实签名/真机安装仍可能失败；代码与构建合同不能替代 provisioning 验收。
- 当前 PRD 没有公开 Widget 授权入口，因此默认拒绝会使生产 Widget 保持空态，直到后续产品明确授权流程。
- WidgetKit timeline 缓存行为只能通过模拟器/静态证据部分验证，最终锁屏和桌面隐私展示仍需真机。

## Assumptions

- `KBLiteManager.userGeneration` 可作为 Widget publication generation 的唯一进程内时序来源。
- `summaryAllowed` 是独立于 Echo `generationAllowed` 的显式系统展示授权，两者必须同时满足。
- 本轮不开放 familyCircle、数字人角色知识或事件描述到 Widget。
