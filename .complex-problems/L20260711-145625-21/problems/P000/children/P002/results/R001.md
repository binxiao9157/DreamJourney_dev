# Widget 发布生命周期已绑定账号 generation

## Summary

已用独立存储层替换 KBLiteManager 的无条件共享 JSON 导出，并建立账号激活、发布、切换、登出、失败失效和 timeline reload 合同。

## Done

- 新增 `KnowledgeWidgetSnapshotStore`，串行维护 active owner digest 与 UUID generation。
- `activate` 先写/撤销共享 active owner，再删除旧快照并 reload；`publish` 同时校验 owner、generation 和共享 digest。
- 快照原子写入、排除备份，并在 iOS 设置 `completeUntilFirstUserAuthentication` 文件保护。
- publish 失败或 KBLite 主文件保存失败时删除共享快照，保持 fail closed。
- `KBLiteManager` init/save/switchUser 接入 store；save 捕获 generation，延迟旧保存会被拒绝。
- 删除旧 `writeToAppGroup`、`kb_widget_data.json` 和 description/raw event 映射。
- metadata 合并保留已有显式 Widget 授权，不由后续知识提取隐式重置。

## Verification

- spy reloader 证明激活、发布和清理会触发 timeline invalidation。
