# Widget 隐私投影模型已实现

## Summary

已建立默认拒绝、显式授权、字段最小化且可独立测试的 Widget 知识投影合同。

## Done

- `KBPrivacyMetadata` 新增向后兼容的可选 `widgetVisibility`；历史 JSON 缺失该字段可正常解码并保持默认拒绝。
- 新增 `KnowledgeWidgetPrivacyPolicy`、schema v2 `KnowledgeWidgetSnapshot` 和最小 `KnowledgeWidgetEventSummary`。
- allowlist 同时检查当前 owner、`generationAllowed`、`summaryAllowed`、`personal`、`confirmed`，任一不满足均不投影。
- owner 与 event 标识使用 SHA-256 digest；标题压缩空白并限制为 80 字符；description/sourceRefs/raw ID 不进入 schema。
- 新增独立模型 smoke 和 runner，测试先失败于缺少实现，完成实现后通过。
