# 修复 Widget target 的可交付工程合同

## Problem Definition

当前主 App 不嵌入 Widget extension，主/Widget 没有相同 App Group entitlement，Widget bundle/team 也不跟随主 App，本轮新增服务和 reader 文件尚未加入 target，导致代码即使正确也无法随产品构建交付。

## Proposed Solution

手工、最小化更新 pbxproj：加入三个 Swift 文件引用/build files，给主 target 增加 Embed App Extensions copy phase 与 Widget dependency，设置两 target 的 entitlements、统一 App Group build setting、Widget bundle/team 派生。更新主/Widget Info.plist 的 App Group key，扩充主 entitlements并新增 Widget entitlements。通过 build settings、Simulator/generic iPhoneOS 构建和 `.appex` 产物检查验证。

## Acceptance Criteria

- 新文件分别属于正确 sources phase。
- DreamJourney App 的 build phases 包含 Embed App Extensions，依赖 DreamJourneyWidget target，并拷贝 widget product。
- Debug/Release 两侧均配置同一 App Group setting 和各自 entitlements。
- Widget PRODUCT_BUNDLE_IDENTIFIER 为 `$(DREAMJOURNEY_PRODUCT_BUNDLE_IDENTIFIER).widget`，DEVELOPMENT_TEAM 同源。
- Simulator/generic iPhoneOS 构建通过，App 包内含 `PlugIns/DreamJourneyWidget.appex`。
- 不写入任何本地证书、密钥或 LocalConfig 内容。

## Verification Plan

运行 `plutil -lint`、`xcodebuild -showBuildSettings`、Simulator build、generic iPhoneOS build，并检查产物路径和嵌入扩展 Info.plist/bundle ID；最后运行新增模型 smokes。

## Risks

- pbxproj ID、phase 顺序或 dependency proxy 配置错误会造成构建失败，必须以实际产物而不是文本存在为准。

## Assumptions

- 仓库默认 App Group 名称继续为 `group.com.dreamjourney.shared`，可通过 `DREAMJOURNEY_APP_GROUP_IDENTIFIER` 覆盖。
- 真实设备 capability/provisioning 由后续外部验收完成。
