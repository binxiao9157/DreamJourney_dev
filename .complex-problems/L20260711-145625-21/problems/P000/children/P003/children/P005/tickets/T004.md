# 用纯校验策略升级 Widget 快照读取

## Problem Definition

Widget 无条件解码旧 events 数组并把 description 带入 timeline，无法证明数据属于当前账号，也不能在旧 schema、损坏文件或身份撤销时 fail closed。

## Proposed Solution

重写 Widget shared models 为 schema v2 最小模型，新增不依赖 WidgetKit 的 `KnowledgeWidgetSnapshotReader`，输入 data 与 active owner digest 后完成解码和严格校验；provider 只负责获取可配置 App Group 文件/defaults 并调用 reader。Timeline entry 只保留标题/日期，view 删除正文并将真实摘要标记为 privacy sensitive。

## Acceptance Criteria

- reader 仅接受 schemaVersion=2 且 non-empty activeOwnerDigest 与 snapshot ownerDigest 完全一致的数据。
- nil/空/错 owner、旧 schema、损坏 JSON 均返回空数组。
- provider 使用 `kb_widget_snapshot_v2.json` 和共享 active owner digest key，不保留旧文件兼容降级。
- entry/view 完全移除 description；placeholder 不使用具体人物或家族故事。
- 独立 reader smoke 实际解码 JSON 并覆盖成功与失败矩阵。

## Verification Plan

新增 reader smoke 与 runner，直接编译 SharedModels/reader；运行源码负向检查确认 description 和旧文件名不在 Widget 链路；P006 工程接线完成后再做 target build。

## Risks

- 主 App 和 Widget 各自定义相同 schema，后续需静态 gate 防止字段漂移。

## Assumptions

- active owner digest 由主 App store 写入同一 App Group defaults。
