# 实现 iOS 结构化提取和 Persona-bound fallback

## Problem Definition

iOS 证据上送、精提取频率、本地置信度和 family persona 降级策略不一致。

## Proposed Solution

扩展 backend client 的 extract payload 为 indexed turns；在 KBLite graph 保存兼容的 lastBackendExtractionSession/Date 水位；统一 generation fact predicate；抽出纯 Swift Echo knowledge context policy，用当前 gate 校验 packet identity 并决定 local fallback，family 默认拒绝本地私有 KB。

## Acceptance Criteria

- structured turns 正确标记 user/assistant 和 index。
- 每三次会话能重新触发后端精提取。
- low/medium fact 不进入本地生成。
- family fallback 和错身份 packet 被拒绝，personal self 正常。

## Verification Plan

新增纯 Swift model smoke 和 static guard，运行三方合并 smoke、release regression 及 generic builds。

## Risks

- 旧图谱解码必须使用默认水位保持兼容。
- 不能在 family 失败时静默切回 viewer 数据。

## Assumptions

- 旧后端可忽略 additive turns 或由客户端兼容重试 legacy 请求。
