# 实现 `/kb/extract` 证据策略 V2

## Problem Definition

普通 transcript 无法让服务端可靠区分用户事实和 assistant 回复，provider 返回来源也未被验证。

## Proposed Solution

新增独立 evidence policy helper，解析 structured turns、生成 provider transcript 与 user turn allowlist，并在 provider 响应后按实体统一过滤 `sourceTurnIndices`。`/kb/extract` 保持 legacy transcript 兼容，v2 返回无正文统计摘要；DeepSeek prompt 明确 user-only 规则。

## Acceptance Criteria

- 合法 user evidence 被接受；assistant-only、缺失、越界来源被过滤。
- v1 dryRun 和既有调用继续工作。
- response/log 不回显 turn 正文。

## Verification Plan

新增 helper 单测、FastAPI endpoint 单测和 memory evidence smoke，并运行后端全量验证。

## Risks

- provider 遗漏 index 时 v2 会过滤；不得以 fail-open 修复召回率。

## Assumptions

- provider JSON 的四类实体继续兼容当前 `KBExtractionResult`。
