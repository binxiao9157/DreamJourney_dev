# iOS payload conflict 恢复成功检查

## Verdict

成功。普通 pending 与治理 outbox 均有明确且有界的 conflict disposition，结构化错误、持久化兼容、队列非阻塞和编译证据覆盖原问题。

## Criteria Review

- 结构化识别：BackendErrorContext 保留 code/operationId/detail。
- 普通 mutation：旧 pending 在刷新前删除，本地图谱由三方合并保留并生成新 operation ID。
- Governance：首次 rotate、第二次 quarantine；completion 随 ID 迁移，隔离项被 dispatcher 跳过。
- Outbox：同语义 no-op、不同语义拒绝、replace 原子写文件、旧 JSON 默认字段兼容。
- 回归：model/client/coordinator/pipeline/cross-repository gate 和 Simulator build 通过。

## Residual Risk

当前工程缺少可注入网络错误的 Coordinator XCTest，运行时顺序由纯模型 smoke、源码顺序门禁和编译共同证明；真机/线上错误注入属于后续验收。
