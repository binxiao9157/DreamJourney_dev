# PC-00-03 回滚

产品确认结果是收敛首版可见范围。出现回归时优先 forward-fix 以下不变量：

1. 普通用户音频、视频上传和处理固定为 `productClosed`，不得恢复 mock 成功状态。
2. 普通 Owner 媒体只公开图片和文档；内部音视频测试代码不得进入 Release 入口。
3. KBLite 用户页面、路由和导出保持隐藏，后端原有隔离读写合同不改变。
4. 客户端完整账户导出保持关闭；运维脱敏导出继续为 `DEFERRED`。
5. 图片、文档、普通消息中心和后续正式记忆 Markdown 导出不得被误伤。

不得通过旧 feature flag、本地 QA 参数、历史策略快照或 mock Provider 重新开放关闭能力。重新开放必须由新的产品决策和独立 Work Item 执行。
