## 已实现

- `/live` 为匿名、no-store、免业务 UoW 的纯进程存活探针。
- `/ready` 每次重新验证 Postgres pool checkout、读操作、临时表写入与 rollback、migration head/checksum、生产必需 Auth 配置；required component 非 ready 时返回 `503`。
- 数据库写 probe 使用 `TEMP TABLE ... ON COMMIT DROP`，设置 2 秒 statement timeout，并在返回连接池前强制 rollback。
- migration 校验复用 `PostgresMigrator.verify_connection`，不复制 head/checksum 权威逻辑。
- response 只输出 component/status/reason/evidenceTimestamp，不返回 DSN、SQL、checksum、凭据或异常文本。
- DeepSeek、火山语音、腾讯数智人等扩展 Provider 不进入基础 readiness；Provider 故障只降对应 capability。
- `/health` 保留旧字段但明确 deprecated，并指向 `/live`、`/ready`。
- `/live`、`/ready` 已登记为 PUBLIC 基础设施路由；不绑定用户 owner，也不经过业务认证或 UoW。
- Docker API healthcheck 已切到 `/ready`；release regression 新增静态门和可选 deployed gate。
