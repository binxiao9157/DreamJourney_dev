## 2. 核心产品定义

寻梦环游是一款面向个人与家庭的记忆沉淀和回响陪伴产品。用户记录文字和多媒体素材，经系统整理与本人确认后形成可追溯的正式记忆；回响只使用当前身份有权访问的正式记忆或已发布副本，不把 AI 推断、运行时结果或家庭关系本身当作事实和授权。

核心原则：

1. Source 不等于正式记忆。
2. Candidate 必须由 Owner 接受或纠正后才能形成 MemoryVersion。
3. 每次纠正创建新版本，不覆盖历史事实链。
4. 私人域、发布域和运行时域隔离。
5. Family 关系不自动授予私人 V4、声音或数字人权限。
6. 无相关记忆时返回记忆缺口并转访谈或家庭贡献，不编造答案。
7. 产品页面不展示 Citation，服务端保留类型化引用、哈希和审计轨迹。

## 3. 用户与权限

| 角色 | 资格 | 产品权限 |
|---|---|---|
| Owner | 认证主体与 Vault Owner 一致 | 管理自己的 Source、Candidate、MemoryVersion、Projection、发布和数据权利 |
| Family | FamilyRelationship + 专项 Grant | 查看关系状态、接受邀请、按授权贡献；不能读取对方私人 V4 |
| Visitor | 有效 ShareGrant + VisitorSession | 只读 PublicProjection；撤权、过期或暂停后立即失效 |
| Operator | 独立后台 Principal/Scope | 管理运行元数据，不默认读取用户私人内容 |
| Admin | 独立强认证与审计 | 配置和审计；访问私人内容需要额外审批 |
| superTest | 显式 testRole + entitlements | 可见全部已启用测试功能，但不能绕过 Vault、Grant、授权和审计 |

生产环境中的正常认证 Owner 均可使用家人管理。测试白名单只控制测试验证码；测试角色和功能权限必须由管理员显式分配，不成为生产用户资格系统。

## 4. 信息架构

登录后保持三个一级页面：

1. 记忆档案：素材、待确认记忆、正式记忆、自传/故事、访谈和受权贡献。
2. 回响：文字问答、Live 实时语音、记忆缺口转接和语音播放。
3. 我的：个人资料、消息中心、家人管理、心境追踪、音色复刻、发布授权、法律、数据权利和账户管理。

记忆档案与回响右上角常驻消息铃铛；有未读消息时显示数字红标。消息中心支持一键已读和一键删除已读通知。

“我记录的记忆”表示 Source/素材，“我的自传”表示阅读视图，“正式记忆”表示当前 MemoryVersion 总览，三者不得混用。

## 6. 正式记忆 V2

1. 一级 `kind` 只允许 `experience`、`knowledge`、`emotion`。
2. `facets` 支持人物、时间、地点、关系、情绪、价值观、人格、可信度和来源。
3. AI 推断必须标记 `evidenceMode=inferred` 和不确定性，不能冒充 Owner 陈述。
4. 新 Candidate 默认使用 `owner-truth-v2`；V1 继续可读，不批量伪造 facets。
5. Owner 更正正文或 facets 时创建新 MemoryVersion、correction link 和 DecisionReceipt。
6. 未识别 schema 进入 quarantine，不进入 Projection 和 Echo。
7. 正式记忆展示保留 current + 3 个历史快照；用户不能手动删除历史快照，第 4 个历史快照由系统滚动替换最旧快照。PublicationVersion 和法定删除按各自规则处理。

## 7. 回响与身份路由

Owner 自己提问时：`SearchDocument -> Top-K MemoryVersion -> Authority/版本/哈希复核 -> Context Packet -> DeepSeek`。

查询他人时：

1. 切换 Family 只切换展示身份，不创建对方 OwnerTruthCommandContext。
2. 有有效 ShareGrant 时建立 VisitorSession，读取 PublicProjection。
3. 无 Grant 时显示无权访问或引导贡献。
4. 严禁回退 Legacy Archive/KBLite 读取家人私人事实。
5. 无命中返回 gap，不回退未确认素材。

## 8. 多媒体处理

统一链路为：上传意图 -> 私有对象存储 -> 完整性校验 -> 安全扫描 -> 类型处理 -> ExtractionResult -> Candidate -> Owner 确认。

首版处理范围：

- 图片：OCR、图片描述及人物/时间/地点候选。
- TXT/PDF/DOCX/Markdown：正文、标题、段落和来源片段。
- 音频和视频：入口、上传和处理暂时关闭；保留代码不代表产品可用。

处理失败保留 Source 和对象，不生成伪 Candidate；外部处理前必须取得用途明确的同意。

## 9. 发布与 Visitor

Owner 从正式记忆中多选 current MemoryVersion，形成 PublicationDraft；可编辑公开标题、说明和公开正文，预览隐私与 AI 披露，二次确认后生成不可变 PublicationVersion 和 PublicProjection。

共享内容变更必须创建新草稿和新版本。ShareGrant 可创建、查看、撤销和过期；失效后现有 VisitorSession 立即停止读取。

Publication/Visitor 是目标产品功能，不再使用 M2、QA-only、Closed Beta 等用户可见或代码类名。上线仍需满足成年人身份、权限、安全、数据隔离、Provider readiness 和部署 Gate。

## 10. 导出与数据权利

用户产品入口导出单个 UTF-8 Markdown，只包含 current MemoryVersion 的正文、kind、已确认 facets、时间和版本号，不包含 Source、Candidate、历史正文、媒体二进制、凭据和内部审计。

客户端不提供完整账户数据导出入口。脱敏完整数据仅能由用户联系平台、签署协议并经过运维权限、审批和审计后导出；全链路必须留痕且合法合规，该运维能力本阶段延期、不视为已实现。

### 10.1 KBLite 用户边界

KBLite 仅作为用户不可见的后台兼容逻辑。现有后端读写行为和权限保持不变；本轮不新增 KBLite 页面、不因隐藏而修改其数据权限，也不得借兼容逻辑绕过账户、Vault、Grant 或跨账号隔离。

### 10.2 应用内消息中心

1. “我的”页面提供消息中心入口。
2. 记忆档案和回响右上角常驻铃铛，未读消息显示数字红标。
3. 消息中心聚合 Candidate 整理、投影/导出、家庭邀请与贡献、授权撤销、账户安全及可重试任务状态。
4. 支持单条已读、一键已读和一键删除已读；未读消息不能被“一键删除已读”误删。
5. 通知只携带最小元数据，打开 App 后重新鉴权读取；时光信和延迟回复事件保持关闭。

## 11. 暂时关闭能力

### 11.1 数字人

- Release Policy 和 Runtime Capability 同时关闭。
- iOS 不展示数字人容器或状态文案。
- Echo 不请求、续约或恢复腾讯数字人 Session。
- 后端代码与 Adapter 保留，但普通产品流量失败关闭。

### 11.2 时光信与延迟回复

- iOS 隐藏创建、信箱和状态入口。
- 后端拒绝新建，不调度新投递。
- 产品尚未正式发布，不存在生产历史数据迁移或补发；开发/测试数据不视为生产历史。
- 普通任务完成通知继续使用 APNs/应用内消息。

## 12. 发布与运行口径

取消 M1/M2/M3/M4 和 QA/封闭试点作为产品范围和页面命名，不等于一次性无条件放量。

以下 Gate 继续强制执行：

1. 真实认证与账户状态。
2. Owner、Family、Visitor 和 Operator 权限。
3. Vault、ShareGrant、用途授权和 Authority Epoch。
4. Provider 配置、地域、健康、配额和删除能力。
5. Worker、对象存储、迁移和恢复 readiness。
6. 紧急关闭、最低客户端版本和故障降级。
7. 适用的隐私、法律、安全、真机和生产证据。

功能代码存在但 Gate 未通过时必须显示明确不可用或隐藏，不得伪装成已经完成。

## 13. 验收总则

1. 35 个需求编号必须分别标记为完成、明确关闭或外部 Gate 阻断。
2. superTest 能测试已启用功能但不能读取未授权 Vault。
3. Family 切换不能读取家人私人 V4。
4. 正式记忆支持全文、搜索、版本和二次确认编辑。
5. Echo 使用 query-ranked current MemoryVersion，页面不展示 Citation。
6. 图片和文档解析结果必须有 Source 引用并经过 Owner 确认；音频和视频保持关闭。
7. Markdown 仅包含当前正式记忆。
8. Publication/Visitor 完成从创建到撤权的 App 闭环。
9. 数字人、时光信和延迟回复关闭期间调用量为零。
10. 任何权限撤销、账户切换或注销都必须阻断旧异步结果。
11. 密码和 OTP 两种登录均有完整成功、失败、重置、锁定和会话撤销验证。
12. 消息中心未读数字、一键已读和删除已读在三个一级页面状态一致。
