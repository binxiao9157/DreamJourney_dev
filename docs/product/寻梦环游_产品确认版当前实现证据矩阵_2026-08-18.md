## 2. 状态定义

| 状态 | 含义 |
|---|---|
| `IMPLEMENTED` | 目标代码和主要非真机合同已具备 |
| `PARTIAL` | 已有可复用基础，但缺目标页面、接口、路由或生产闭环 |
| `MISSING` | 未找到目标实现或现有实现不满足目标模型 |
| `TARGET_CLOSED` | 代码存在，但产品确认要求关闭入口和调用 |
| `COMPATIBILITY` | 后台兼容行为存在，用户不可见；具体读写保持当前产品确认边界 |
| `DEFERRED` | 产品规则已确认，但明确不在本阶段实现 |
| `EXTERNAL_GATE` | 代码存在，仍依赖真实 Provider、部署、法律或真机证据 |

## 5. 不应重复开发的能力

以下能力已有充分代码基础，后续只做目标差异和回归，不从零重写：

- Source -> Candidate -> Decision -> MemoryVersion 主链路。
- 引导式访谈、话题偏好、会后整理和待确认批次。
- Echo trace、evidence bundle、Citation 基础和记忆缺口转接。
- 家人邀请、家庭贡献和撤权状态机。
- 音色 profile 生命周期、人工接受、暂停、删除和 PCM binding。
- Publication/Visitor 领域对象和默认关闭基础。
- 数据注销、恢复、导出 Job、删除回执框架。
- Provider Adapter、Runtime Capability、Release Policy、Worker/Outbox/dead-letter 基础。

## 6. 当前发布判断

产品目标已经明确，但当前仍不能标记为产品确认版完成或生产可发布：

1. GAP-01 至 GAP-13 尚未全部闭环。
2. 数字人、时光信和延迟回复尚未按新目标形成统一关闭证据。
3. 真实 OTP、私有对象存储、媒体 Worker、图片 OCR/视觉处理、Ownership enforce 等外部/部署 Gate 未关闭。
4. Publication/Visitor 虽属于目标开放范围，当前 App 闭环和生产权限证据仍不足。
5. 密码双登录已完成代码、部署和非真机验收；音色创建 5 次上限、家庭解除和统一消息中心仍待闭环。
