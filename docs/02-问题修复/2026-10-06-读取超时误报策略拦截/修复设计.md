# DJ-READ-TIMEOUT-01 读取超时误分类：修复设计

日期：2026-10-06。用户授权先归档设计、再按设计开发；本次仅本地开发与受控回归，不部署、操作手机/生产、调用真实模型或commit/push。

## 1. 问题与目标

当前iOS Client的候选读取专用入口、通用OwnerTruth读取入口和只读恢复预算路径，把读取截止归为featurePolicyDenied；通用文案误报发布策略拦截，领域进一步映射permissionUnavailable/releasePolicyDisabled。Echo对旧reason有部分特判，不代表其他页面正确。候选策略刷新失败还可能遮蔽原始网络错误。

目标：超时、读取次数耗尽、读取取消与真正权限拒绝明确分离；页面显示读取问题，保留恢复机会，但不在本次失败后自行增加请求。历史API阻塞首因、账号偶发退出及模型整理问题不归入本修复。

## 2. 影响范围与实现

1. DreamJourneyBackendClient.swift：增加仅用于有界只读操作的ReadError，deadlineExceeded/budgetExhausted/cancelled三类及不暴露内部代码的文案。替换候选与通用读取计时器、GET预算、只读前置取消/截止、401恢复预算、runtime恢复预算中错误归类；诊断仍保留已有trace/计数和兼容原因标签。策略刷新失败保留实际超时/传输错误，不一律包装策略拒绝。
2. OwnerTruthContracts.swift：候选读取Notice映射为网络读取不可用、请求失败或已取消；既有review failure disposition的普通可恢复分支不再把这三类当权限终止。不新增自动重试，不改未知写结果或审核命令重放规则。
3. EchoViewController.swift：ReadError明确映射timeout/budgetExhausted及取消/失效；沿用现有只读状态观察，不新增按钮、用户整理状态或业务重试。旧reason兼容分支保留。
4. OwnerTruthContractsTests.swift：真实Client+受控URLProtocol到UseCase/Controller的截止、预算、刷新失败及迟到响应测试；真实权限拒绝、账户变化、401刷新、未知写保持回归。

产品影响仅iOS读取错误的分类及呈现。后端、数据库、Provider合同/提示词、正文采集、持久化、分页/主题发布、审核写入、开麦截止、PCM和告别音色不改。共享Client/领域文件被多入口依赖，必须完整编译及相关回归，不能仅改字符串交付。

## 3. 不变量

- 原读取总时限、GET/策略/认证/runtime次数不变，超时后不自动重开新的读取意图。
- 完成一次、迟到响应不覆盖、账号隔离不变；真正deny仍为权限拒绝。
- 不把读取失败说成正文丢失或候选生成失败；不提前显示整理完成。
- 未知结果的POST/确认/激活不自动重发。ReadError仅用于携带读取上下文的链路，不从普通写请求制造新的retry权限。
- 新类型不影响已通过的短/长保存链，冻结后按当前十分钟产品范围验收。

## 4. 验证计划

A. 修改生产代码前，在当前干净版本增加同断言业务测试，执行并留存红：候选截止不应permissionUnavailable，正式列表超时不应显示发布策略，通用只读错误应是可恢复读取失败。以真实Client发起并hold响应，避免仅手造枚举证明接线。
B. 修复后同测试转绿；补候选/通用GET预算、策略刷新网络超时、真正deny、账户变化、迟到回调与完成次数等边界。确认无额外GET/POST。
C. 最终iOS OwnerTruth及音频/认证回归；生产Manager受控SDK开麦/告别/停止持久化专项；通用iOS无签名构建。实际xcresult结果与跳过入口单列。
D. 使用既有隔离API/Worker/PG和客户端集成工具，执行独立短场A→逻辑十分钟→独立短场B，验证待确认生成、确认、正式读取及原文/事实集合。模型用受控HTTP，仅作本地证据。若现成工具只覆盖后端，必须明确客户端读取专项另证，不宣称模拟器全链通过。
E. 冻结指纹、保存修前/修后结果与受影响文件。产品/测试后续变化使相关旧结果失效时重跑。真实Provider/部署/真机/物理十分钟/声学本轮NOT_RUN，后续由用户发起。

## 6. 实施中补充的同范围接线细节

- 首轮扩大验证发现：候选UseCase的提交前策略缓存检查，会在策略刷新超时时先覆盖成qaOnlyDisabled。失败响应不提交数据；仅对有界读取错误或底层URL错误保留原失败。成功响应仍必须通过策略检查，账号/代次校验及写操作权限门禁保留。
- 候选Notice及Echo恢复复用现有ownerTruthURLFailureCode解包方法，识别Alamofire等包装中的URLError；不创建新的网络重试。
- 通用读取入口将“账号无效”和“上下文已截止”分开检查，账号无效仍优先拒绝；有效账号下已截止读取返回deadlineExceeded，避免另一处误报账号变化。
- 这些均属于第2节列明的读取分类/下游映射范围，无后端或保存链功能扩张。首轮绿测失败与一次新增测试访问私有类型的编译失败保留，最终以完整同版结果验收。
